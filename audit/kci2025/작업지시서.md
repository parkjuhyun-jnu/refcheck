# 게재 논문 참고문헌으로 refcheck 오판 바로잡기 — 클라우드 세션 작업 지시서

이 파일만 읽고 끝까지 수행할 수 있게 적었습니다. 저장소 밖의 맥락은 필요하지 않습니다.

## 목적

refcheck.kr(이 저장소)은 학술 원고의 참고문헌을 검증·교정하는 서비스로, 문헌정보학 분야
4개 학회(한국도서관정보학회·한국문헌정보학회·한국비블리아학회·한국정보관리학회)가 함께
운영합니다.

4개 학회지에 **2025년 게재된 논문 240편의 참고문헌 7,911건**(KCI 등록 서지)을 이용자
원고처럼 refcheck에 넣어 본 결과가 `results.jsonl`입니다. 게재본은 편집위원회 검토를
거친 최종본이라 거의 맞습니다 — 운영자 말로 "모두 맞은 것은 아니지만 에러가 적다".
그러므로 **refcheck가 '틀렸다'고 한 항목은 대부분 refcheck 쪽 오판 후보**입니다.
원인별로 묶어 판정하고, refcheck 잘못은 코드로 고쳐 주세요.

## 자료

- `results.jsonl` — 한 줄이 참고문헌 1건
  - `j` 학회지(liss·kslis·kbiblia·kosim) · `art` KCI 논문 번호 · `i` 목록 안 순번
  - `kci` KCI에 등록된 원래 필드(게재본의 서지 — 이번 점검의 기준)
  - `entry` refcheck에 넣은 항목 · `formatted` refcheck가 만든 참고문헌 문자열
  - `v` 검증 결과(`status`·`source`·`detail`·`meta` = 정보원이 돌려준 서지)
  - `sugg` 교정 제안 · `pnote` 면수 확인 비고 · `issues` 형식 경고 · `loss` 형식 변환 뒤 사라진 값
  - `flags` 오판 후보 신호 · `note` 오판이 아닌 것(`not_checked` 조회 안 하는 자료,
    `retry` 외부 DB 일시 오류)
- `요약.md` — 신호별·학회지별·유형별 건수

| 신호 | 뜻 |
| --- | --- |
| `status:not_found` | 어느 정보원에서도 못 찾음 — 화면에 '미확인' |
| `status:mismatch` | 찾았으나 서지가 다름 — '서지 불일치' |
| `status:suspect` | 의심 |
| `status:link_dead` | URL이 열리지 않음 |
| `suggest:<필드>` | 그 필드를 고치라는 교정 제안 |
| `page_note` | 면수 확인 비고 |
| `issue` | 형식 경고 |
| `loss:<필드>` | KCI에 있던 값이 형식 변환 뒤 사라짐('원문과 같은데 빨간색'의 근원) |

### 점검 장치가 만든 인공물 — 오판으로 세지 마세요

- `entry.raw`는 KCI 필드를 이어 붙여 만든 문자열입니다. 실제 원고 원문이 아니므로
  `issue`·`loss` 가운데 이 합성 방식 때문에 생긴 것은 제외합니다.
- KCI는 단행본 **발행지를 등록하지 않습니다** — '출판지 누락' 경고는 자료 한계입니다.
- KCI는 전자저널의 **논문 번호(article number)를 따로 두지 않습니다** — '면수 누락(온라인
  학술지는 아티클 넘버)' 경고는 대부분 자료 한계입니다. 다만 게재본에도 면수·논문 번호가
  없는지는 `kci.page`로 확인하세요.
- KCI의 서양 저자 `Wilkinson M`(밴쿠버식)은 `Wilkinson, M.`으로 바꿔 넣었습니다.
- 영문 변환 항목(국문 문헌의 영문 표기)은 같은 논문 안 국문 항목과 DOI가 같거나 연도·권·
  호·면수가 같은 것만 표시했습니다(`entry.is_en_conversion`).
- 07 기타자료는 제목·저자만 있습니다.
- AI 구조화 단계는 건너뛰었습니다. 여기서 보는 것은 **검증·교정 제안·형식 변환 층**입니다.

## 판정 분류

| 분류 | 뜻 | 할 일 |
| --- | --- | --- |
| A | refcheck 오판 | 고친다 |
| B | 등록 데이터(KCI·Crossref·RISS 등)가 틀림 | refcheck가 그 값을 믿고 교정을 제안했다면 A로도 본다 |
| C | 게재본 자체가 틀림(refcheck가 맞음) | 건수와 사례만 보고 |
| D | 정책 판단이 필요 | 운영자에게 질문으로 남긴다 — 임의로 정하지 말 것 |
| E | 범위 밖·개선 아이디어(정보원 추가 등) | 제안으로만 남긴다 |

## 지켜야 할 정책 — 운영자와 확정된 것, 바꾸지 마세요

1. **국문 논문은 DOI가 있어도 KCI 서지가 기준**, Crossref는 DOI 실존 확인용입니다.
2. **서양 학술지**는 Crossref와 ERIC(인쇄본)가 권·호·면수에서 갈리면 원고와 같은 쪽을
   기준으로 하고 제안 없이 '두 정보원이 다름'만 안내합니다.
3. **게재면수의 전거는 발행본(인쇄면)**입니다. 등록 면수와 원고가 첫 면이나 끝 면 한쪽만
   1쪽 다르면 교정 제안 대신 '발행본 면수 확인' 비고만 답니다. KCI `<verified>`가 N인
   레코드의 면수는 교정 근거로 쓰지 않습니다.
4. 권 없이 **통권만 매기는 학술지**는 그 번호를 권 자리에 씁니다('국어교육, 170, 81-122.').
5. **저자 영문명은 자동으로 바꾸지 않습니다.** 정보원이 갈리면 나란히 보여 주기만 합니다.
6. **등록 데이터는 언제든 틀릴 수 있습니다.** 한 정보원만 근거로 교정을 제안하지 않습니다.
7. 영문 제목 부제는 소문자가 원칙이고, 한국도서관정보학회만 대문자입니다
   (`app/formatter.py`의 `ORG_SUBTITLE_CASE`, 57권 2호부터 바뀐 규정).
8. 온라인 자료 접두어는 국문 `출처:`, 비국문 `Available:`입니다.

## 진행 방법

1. 준비: `pip install -r requirements.txt` 후 `python tools/audit_replay.py`를 돌려
   기준선을 봅니다(코드를 안 바꿨으면 전·후가 같아야 정상).
2. **묶기**: `flags`가 있는 항목을 신호·`v.source`·`v.detail`·자료 유형별로 묶어 원인 가설을
   세웁니다. 예: Crossref 제목 검색이 수록지가 다른 문헌을 '확인'으로 짝지음 / RISS 학위논문
   연도 ±1 / 정부 발간 보고서 미확인 / 링크 죽음 / 형식 변환 뒤 값 소실.
3. **판정**: 묶음마다 대표 사례 3~5건의 `kci`와 `v.meta`를 대조해 A~E로 판정합니다.
   **A로 판정하기 전에 반증을 시도하세요.** 서브에이전트를 쓸 수 있으면 독립 검토자 2~3명에게
   "refcheck가 사실은 맞았다"는 쪽 논증을 맡기고, 과반이 반박에 성공하면 A를 기각합니다.
   묶음이 많으면 묶음별로 병렬로 판정해도 됩니다.
4. **수정**(A만): 가장 작은 변경으로 고칩니다.
   - 교정 제안·형식 층(`app/main.py`의 `_build_suggestions`·`_page_check_note`,
     `app/formatter.py`)을 고쳤으면 `python tools/audit_replay.py --show <신호>`로 그 신호가
     줄었는지, **새로 생긴 신호가 없는지** 확인합니다.
   - 조회 층(`app/verify.py`·`app/verify_kr.py`의 짝짓기·판정)은 재생 도구로 잴 수 없습니다.
     `results.jsonl`에 기록된 `meta`로 외부 호출 없는 단위 시험을 만들어 확인합니다.
   - 고친 사례는 실제 사례 그대로 회귀 시험에 고정합니다(`app/test_crosscheck.py`의 기존
     방식을 따르세요).
   - 기존 시험이 모두 통과해야 합니다: `python app/test_crosscheck.py`,
     `python app/test_conv_section.py`, `python app/test_history.py`, `python app/test_law.py`.
5. 코드 주석·커밋 메시지는 한국어로, 기존 코드의 습관(무엇을 왜 바꿨는지 + 실측 날짜·사례)을
   따릅니다. 버전은 `app/main.py`의 `APP_VERSION`과 `app/static/index.html`의 `UI_VERSION`을
   **함께** 올립니다(형식 `YYYY.MM.DD-NN`).
6. **보고서** `audit/kci2025/판정결과.md`:
   - 묶음별 건수·판정(A~E)·근거 사례(원문 인용)·조치
   - 수정 전후 오판 후보 수(`audit_replay.py` 출력)
   - D 질문 목록 — 운영자가 답만 고르면 되게 선택지를 붙여서
   - E 제안 목록
7. 풀 리퀘스트로 올립니다. 본문에 보고서 요지를 적어 주세요.

## 하지 말 것

- 운영 서버 접속·배포 — 반영 여부는 운영자가 PR을 보고 정합니다.
- KCI·RISS·국립중앙도서관 조회 — 이 환경에는 키가 없습니다. 판정에 필요한 증거는
  `results.jsonl`에 있습니다. Crossref·OpenAlex·doi.org는 키 없이 되니 필요하면 확인해도 됩니다.
- 매칭 임계값을 근거 없이 바꾸기 — 바꾼다면 그로 인해 바뀌는 판정 수(전/후)를 보고서에 적습니다.
- AI 프롬프트(`app/aiengine.py`) 수정 — 이번 점검은 AI를 거치지 않았으므로 근거가 없습니다.
- `results.jsonl` 수정 — 원자료입니다.

## 시험 실행에서 이미 보인 사례

- **Johnston (2022)** — 게재본(KCI): *Archival Science*, 19(4), 303-327. refcheck는 Crossref
  제목 검색에서 같은 저자의 **다른 문헌**(책 *Archives in a Changing Climate*의 한 장, 101-121,
  DOI 10.1007/978-3-031-19289-0_7)을 '제목 일치 100%'로 확인하고, 면수를 101-121로 고치라고
  제안하며 그 DOI를 출력에 붙였습니다. 수록지가 다른데도 확인으로 처리한 짝짓기 문제로
  보입니다(단, 권 19는 2019년 권이라 게재본의 연도 2022가 틀렸을 가능성도 함께 따져 볼 것).
- **박유진 (2019) 석사학위논문** — KCI는 2019, RISS는 2018로 등록돼 연도 교정을 제안했습니다.
  학위 수여 연도와 제출(등록) 연도가 갈리는 흔한 경우라 D(정책 판단) 후보입니다.
